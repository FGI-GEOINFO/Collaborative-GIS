Collaborative GIS

Collaborative GIS (CGIS) is webmap platform intended for collaborative planning. As a Spatial Decision Support System (SDSS) that enables collaborative planning, in CGIS participants can work together on a shared map workspace each on their own devices. The key features of CGIS are:

  • a map user interface (e.g. offering a shared perspective to the planning situation)
  • a workspace manager (e.g. managing different projects)
  • a data manager (e.g. importing data or connecting to external APIs)
  • a layer manager (e.g. overlaying data)
  • map drawing tools (e.g. sketching planning ideas)
  • an analysis tool (e.g. running on-the-fly analysis on imported data).

For example, the CGIS platform can be used by multiple people working together to discuss, plan, and decide the locations of drone in a box sites, where drones are recharged and stored.

Workspaces

In Workspaces you can login to the system and open, delete, share, and set permissions for workspaces.

Login to Catalogue: You can login to the system using the Layman Portal. When asked about application permissions, authorize reading and writing permissions.
Reload: Reload the list of workspaces
Import a workspace from a file on device: Import your own workspace as a JSON-file.
Add workspace by address: Import your own workspace using a URL.

Searching and Filtering Workspaces

  • Search: You can search for a certain workspace.
  • Filter by map extent: When selected only workspaces that reach the current map extent are shown.
  • Only mine: When selected shows only workspaces that have been created by the user logged in.
  • More: Gives you options to filter with keywords and INSPIRE themes. You can also sort the workspace results by title, date and bounding box.

Opening a Workspace (Click the name of the workspace in question):

  • Open: Open the selected workspace
  • Metadata: Shows thumbnail, URL to the workspace and has a link to the full metadata record
  • Share: Not in use, workspaces cannot be shared into a social network.
  • Set permissions: Select and confirm read and write access rights to be public or private. The rights can be set for everyone or per user.
  • Delete: Delete the workspace.

Data Manager

In Data Manager, you can set permissions for users and remove layers. You can also add layers to the map and import data via URL or from a file. Additionally, you can login to your account and logout.

Searching and Filtering Data

  • Search: You can search for certain data.
  • Filter by map extent: When selected, only data that reach the current map extent are shown.
  • Only mine: When selected, shows only datasets that have been created by the logged-in user.
  • More: Provides options to search within all text, abstract, or title for a dataset. You can also filter to include all data or only services or datasets. Additionally, you can sort the results by title, date, and extent.
  • Arrow bottom right: Set the record count per page.

Adding Data to the Map (Click the name of the data in question):

  • Add to map: Add the selected data as a WMS layer. From the arrow, you can also set the type as WMTS or WFS.
  • Metadata: Displays layer metadata with a link to the full metadata record. You can also add the data to the map as WMS, WMTS, or WFS and zoom to the layer.
  • Set permissions: Define read and write access rights (public or private). These rights can be set for everyone or specific users.
  • Remove layer: Remove data from the Data Manager.

URL: You can add data using one of the following formats: WMS, WMTS, WFS, KML, GPX, GeoJSON, ArcGIS Map Server

File: You can add data from your device using one of the following formats: KML, GPX,GeoJSON, Shapefile, Raster image, Raster rime series. Data can be imported eith by dragging and dropping files or by selecting files from a directory


Layer Manager

In Layer Manager, you can toggle the visibility of layers added to the map as well as edit their opacity or styling. The styling options available depend on the format/file type of the layer. You can also rename layers and zoom to their extent. Layers can also be reordered.

Reorder: Change the order of layers by dragging the layers.
Remove multiple layers: Remove multiple layers from the map or from both the map and the Data Manager.
Remove all added layers: Remove all layers from the map or reload the workspace.
Reset map: Resets the map by removing all added layers and the background map. The background map can be restored by refreshing the browser.
Toggle visibility of all layers: Make all layers on the map visible or invisible.

Additional Information: Layer options with a link to the metadata in ISO19115:2003:

  • Ignore layer extent: Display features or parts of features that extend outside the initial extent.
  • Zoom to layer: Zoom to the extent of the layer.
  • Edit layer: Edit the style of a (WFS) layer. This includes adding style rules and color maps.
  • Rename layer: Rename the layer as it appears in the Layer Manager.
  • Download layer content as GeoJSON: Download the layer content as a GeoJSON file to your device.
  • Copy layer: Add a duplicate of the layer to the map.
  • Remove layer: Remove the layer from the Layer Manager.

Draw

In Draw, you can create point, line, and polygon features in user-generated layers. Additionally, you can perform operations on and between drawn layer features (difference, union, intersection, split). While drawing polygons or lines, hold SHIFT to free-hand draw. Use the Backspace key to delete the last point.

New Drawing Layer

  • Add new draw layer: Create a new empty layer for drawing, which can later be managed in the Layer Manager.
  • Load layer from server: Choose one of your server layers to draw on (e.g., a layer previously created or an analysis layer).
  • Layer title: Specify a title when creating a new layer.
  • Access rights: Define read and write permissions for everyone or specific users.
  • Advanced options: Set a folder (default is "User generated") and default attributes.

Drawing Options

Drawing Options: You can create points, polygons, lines, and circles. When drawing you can also zoom to the drawn features, add an attribute name, and copy and move features. Drawn features can be downloaded as WKT or GeoJSON. Drawn features will have centre point coordinates included. Lines will include their length in kilometres and polygons and circles will include their areas in kilometres.

Selection: Select all features or select features with a bounding box.

Edit: Selected features can be edited by performing operations on and between drawn layer features (difference, union, intersection, split).


Feature Info

Feature Info allows you to see the information about a selected feature (e.g., coordinates and other information saved to the attribute table of the data). The features on layers you have writing rights for you can also copy, move, download, and delete features.


Legend

In Legend you can see the symbols used for each layer loaded on the map. With Reset you can update the view if changes you’ve made are not yet visible in the legend.


Save

In Save you can save the current view as a workspace, which enables collaboration across users. The workspace will be then available in Workspaces. You can also login and logout.

Name: Add the name of the workspace.
Abstract: Write a description of the workspace.
Keywords: You can add keywords.
Thumbnail: Shows the thumbnail for the workspace to be created.
Access: Define reading and writing access to everyone or by per user.
Advanced options: Shows the extent of the workspace. You can edit the workspace extent or use the current map extent. You can also define which layers will be included into the workspace.
Download: Download your workspace as a JSON-file.


Print

Print allows you to print the current map view, with some styling options.

Title: Add a title to the map, e.g., “Drone landing site analysis results.”
Legend: Include a legend for the map layers. You can customize the background color, width, and text position.
Imprint: Add author and abstract details to the map.
Scale: Add a scale to the map as a scale line or scale bar. Choose the scale units (metric, degrees, US inch, or nautical mile).
Print: Save the map view as a PDF. The map will also open in a new tab, where you can save it as an image.
Preview: Preview the map view in a new tab.
Download as PNG: Download the current map view, including added features such as scale and legend, as a PNG image.


Login

You can login to the system using the Layman Portal. When asked about application permissions, authorize reading and writing permissions.

Analysis

The analysis tool allows you to configure and run spatial analysis on layers visible in the Layer Manager. Please notice, only vector layers (WMS) can be included into the analysis, other layer types are filtered.

Result title: Choose a unique title for your analysis result. This will be the name of the created results layer.

Study area: Shows the coordinates of the analysis study area. The analysis will be run on the current map view. Ensure the desired study area is displayed.

Status:

  • On: Include the layer in the analysis. Choose a weight between -1 and 1, where -1 represents very unsuitable areas (e.g., cemetery, daycare) and 1 represents very suitable areas (e.g., parking lot, bare ground).
  • Off: Exclude the layer from the analysis.
  • Difference: Use the layer as a mask to exclude certain areas from the analysis (e.g., waterbodies). This can also define restricted zones (e.g., no-fly zones).

Run Analysis: Starts the analysis. Once notified that the analysis is complete, the result will be visible in the Data Manager, where you can add it to the Layer Manager.

Results panel: Displays metadata for each analysis ran. The metadata includes the parameters set to each layer in the analysis.

Troubleshooting:

  • Make sure you are logged in with correct user. Only analysis users are able to run the analysis.
  • The analysis accepts only vector layers (WMS) from layman.
  • The analysis user must have write permission for all input layers.
  • Remember to give the analysis result unique name. The system is not able to overwrite files with same names.
  • Test running the analysis at smaller scale. The server is not able to handle large analysis areas.
  • Check layer manager for analysis result. The result layer is not loaded to the scene automatically.
  • In some cases, the analysis throws an error even if the analysis was successful. Check layer manager just in case for the layer.
